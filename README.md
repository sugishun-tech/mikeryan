# マイク・ライアン

Nostrの投稿を読んだり、投稿したりするためのクライアント。

## 使い方

1. サイトを開く。投稿を見るだけならログイン不要。
2. 投稿や通知を表示するには、画面の「最新」を押す。
3. 続きを読むには「下」、新しい投稿を追加するには「上」を押す。
4. 投稿するにはログインし、「ポスト」から文章を入力して送信する。
5. フォローやプロフィールの変更は、各プロフィール画面から操作する。
6. 接続先や表示内容を変えるには「設定」を開く。

## 補足

- 投稿・通知は自動では読み込まれない。必要なときにボタンを押す。
- 画像・動画・リンクは投稿内で表示できる。
- 通知に届いたいいね・リアクションには、ハートを押していいねを返せる。赤いハートは送信済み。
- 通常の投稿・返信・リポストにいいねするボタンはない。
- 表示されない投稿がある場合は、設定のミュート条件や接続先を確認する。
