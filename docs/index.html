手動で読み込む

アクセスやスクロールだけでは投稿・公開リストを取得しません。「下に読み込む」「上に読み込む」「最新を読み込む」で最大30件を取得します。上下は実際に見えている投稿が基準です。3ボタンはスクロールに追従します。フォロー・フォロワー・ミュート・リレーも各取得ボタンで読み込みます。

プロフィールの保存と更新

ユーザーのプロフィールだけを永続保存します。取得済みの人は投稿・通知・各一覧・プロフィールページで同じ保存データを使い、再読み込みやログアウト後も再利用します。新しい内容が必要な場合はその人の「プロフィールを更新」を押します。未知の人のページへ移動しただけでは取得しません。

NIP-05の結果も保存時点の情報を使います。認証マークには検証日時を表示します。プロフィール更新で再検証します。プロフィール画像はURLを保存し、画像ファイル本体を保存する機能はありません。

公開リレーを編集する

自分のプロフィールのリレータブでは、取得した公開リレーの削除と、URL・用途を指定した追加ができます。変更時は最新の情報を取得し、署名して公開します。設定ページの接続先リレーは変更しません。他人の公開リレーは編集できません。

設定と保存

投稿・フォロー・フォロワー・ミュート・公開リレー・いいね・問い合わせ結果はキャッシュしません。接続先設定、ログイン公開鍵、下書き、未完了送信、リレー休止情報は従来どおり保存します。秘密鍵はNIP-07拡張機能が扱い、アプリへ保存しません。

初期状態は元の強い表示条件を引き継ぎます。既存の表示条件は自動変更しません。取得の未完了メッセージがある場合は、まず同じ取得ボタンで再試行してください。保存に失敗した旨が表示された場合は、サイトデータの保存許可と容量を確認してください。

取得が未完了の場合

リレーの部分応答で一覧や現在位置を飛ばさず、再試行できる状態を保ちます。フォローと公開ミュートでは名前や相互状態の失敗でユーザー行を省きません。フォロワーはリレー別の検索と本人のフォロー先への直接照会を併用します。空・古い応答で受信済みのフォロー証拠を消しません。最新状態の確認ができなかった場合は警告を表示し、「未確認の候補を再確認」で再試行します。相互関係の証拠がない場合は「相互未確認」と区別します。選択したリレー以外のデータを自動取得するものではありません。
