## 新規試験の範囲

NIP-21の5形式の復号・リンク・カード・取得失敗・複数・深度を確認。naddrのkind/author/d一致と最新版、neventの付加制約、noteとの同一ID共有、未知リレーヒントへ接続しないことを確認。

kind:6 / kind:16の署名済み原本JSON、空・不正・偽造JSON、タグからの取得、元投稿の不存在、再リポスト、循環、q引用と本当の返信の区別を確認。元JSONの存在だけを信頼しないことを検証。

JPEG/PNG/WebP/GIF等の判定、クエリ、NIP-92の拡張子なし画像・alt・dim、1画像制限、通常リンク保持、error、lazy、画面外、重複取得、320/390px表示を確認。

Xでは本物の不透明オリジンsandbox内で製品x-frame.jsを動かし、親DOM・NIP-07に触れないことを確認。公式widgets自体は模擬。成功・拒否・空結果・スクリプトエラー・タイムアウト・偽送信元/トークン・高さ上限・最小幅を確認。

YouTubeではURL判定・iframe属性・通常リンク・準備通知・取得エラー・タイムアウト・偽送信元/オリジン・CSP違反イベント・準備後エラー・手動閉じるを確認。プロバイダー通知は模擬であり、実YouTubeの互換ハンドシェイク成功や再生の確認ではない。

混在する全種類で1枠を共有すること、埋め込み内の媒体を展開しないこと、破損した隣接投稿が正常カードを壊さないこと、長文リンクの128件ごとの置換、画面切替でのリソース解放、投稿・メディアの非永続化を確認。

## 試験アダプターと未検証部分

画面試験は実DOMとネイティブES modulesを使うが、リレー、保存、URL履歴、NIP-07、SHA受渡しはアダプターを使う。新規試験の外部画像・X widgets・YouTubeメッセージもフィクスチャ。CSPは静的記載検査と違反イベントの注入で、実HTTP配信時の適用試験ではない。実行環境のブラウザーURLアクセス制限により、公衆サービスへのナビゲーション・実再生は実施できない。

YouTubeのpostMessage形式は公開IFrame JavaScript APIそのものではない。実サービスとの互換性は未確認であり、変更・通知失敗時は期限でリンクに戻る。X側のCSP、ログイン、地域、広告遮断、第三者Cookieの影響も未確認。公開リレー・実拡張・ネイティブIndexedDB/SharedWorker・タブ間ロックの本番統合、他ブラウザー、長期連続利用は未検証。

localhostの9項目はNode標準WebSocketと製品の通信・暗号検証を、Pythonで起動した実ローカルリレーへ接続して確認した結果。公衆リレーやブラウザーの実WebSocketの検証ではない。
