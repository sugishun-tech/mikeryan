## 今回の重点検証

元投稿を深さ0とし、投稿 → 埋め込み1段目 → 埋め込み2段目が表示されることを確認しました。署名付きの3段目ターゲットも用意し、そのIDへの照会が発生しないことを検査しています。同じ投稿に複数のNostr・画像・動画リンクがあっても直接の埋め込みは1枠のままです。

NIP-21の5形式、q引用、kind:6/16のリポスト、再リポスト、2段目の画像・YouTube、深度上限、祖先循環、参照失敗、最初のURIの不正、重複取得抑制を検査しました。モバイル幅320px/390pxでも入れ子カードが画面外へはみ出さないことを確認しています。

右側の検索フォーム・入力・ボタンが存在しないこと、削除後もアプリが起動すること、モバイル検索が開閉できること、画面名・タブ名が「マイク・ライアン」であること、サイドバー内で名前が1行に収まること、初回にリレー照会を開始しないことを検査しました。
